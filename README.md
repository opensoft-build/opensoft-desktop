# OpenSoft desktop

Downloads for the OpenSoft desktop app (macOS, Apple silicon). This repository holds installers only; no source code.

Latest version: https://github.com/opensoft-build/opensoft-desktop/releases/latest/download/OpenSoft-arm64.dmg

The app is not notarised by Apple yet. On first launch, macOS asks you to confirm: open System Settings > Privacy & Security and choose Open Anyway.
